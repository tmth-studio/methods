# Archive — superseded document-form methods

These files are the document-form (Word / PowerPoint / HTML) versions of the pyramid
methods. They are superseded as the execution route, and kept here for reference.

**Why archived (20 Aug 2026):** the working transport for AI-assistant execution is now
**single-file Python generators** — all content in a DATA section the assistant edits,
layout and structure below marked do-not-edit, self-checks run on every generation. A
code interpreter turns the script into the finished artefact; a write-in document cannot
check its own work.

| File | What it was |
|---|---|
| `Pyramid_Principle_Workbook.docx` / `.html` | Guided write-in workbook — Flow A (analysis) + Flow B (presentation) |
| `Pyramid_Methods_Comprehensive_Final.docx` | Combined methods document |
| `Pyramid_Deck_Templates.pptx` | T1–T34 slide template library |
| `pyramid-deck-fairyfoodmother.html` | Worked example — HTML deck build |

The replacement Python generators live in the repository root as they ship. The
human-facing reference remains live at
[tmth-studio/pyramid-method](https://github.com/tmth-studio/pyramid-method).

## The Pyramid Method: A Working Reference

A comprehensive, human-facing guide to Barbara Minto's Pyramid Principle — for authors, reviewers, and anyone building structured business documents.

**Start here:** [`reference/README.md`](reference/README.md) — choose between the [full reference (~8,500 words)](reference/full-reference.md) or [five focused parts](reference/docs/).

**Why two formats?** The LLM standards above teach an AI to execute the method mechanically. The reference guide teaches *you* to think in pyramids — essential if you're going to review what your AI produces or author your own work. They're companions: read the reference to understand; use the LLM standards to delegate execution.

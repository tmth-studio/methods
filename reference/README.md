# The Pyramid Method: A Working Reference

A practical guide to structuring analytical and strategic writing, based on the method originated by **Barbara Minto** (*The Pyramid Principle*). All prose and examples in this repository are original. This is an independent reference work; it is not affiliated with or endorsed by Barbara Minto or her publishers. For the authoritative treatment, buy the book.

## The method in one paragraph

State your answer first, then support it in layers: each idea provokes a question (*why? how? which?*) that the ideas beneath must answer exactly. Group supporting ideas so they are the same kind of thing, mutually exclusive and collectively exhaustive, in a deliberate order — and make every parent idea an earned summary of its children, never a label. Introduce the whole with Situation → Complication → Question → Answer, so your message lands as the answer to a question the reader is actually asking. Do the thinking with logic trees; do the telling with the pyramid.
